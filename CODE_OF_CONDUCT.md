# Code of Conduct

SST is intended to be a useful community project for DayZ server owners, admins, and modders. Please keep discussion practical, respectful, and welcoming.

## Expected Behavior

- Be respectful of different experience levels.
- Keep criticism specific and constructive.
- Share enough context for others to reproduce issues.
- Avoid posting secrets, server credentials, private player data, or logs that expose personal information.

## Unacceptable Behavior

- Harassment, threats, hate speech, or personal attacks.
- Publishing private credentials or personal data.
- Repeated spam, trolling, or bad-faith disruption.
- Pressuring maintainers or contributors for unpaid support.

## Reporting

Report conduct concerns privately to the project maintainers. Include links, screenshots, or logs where useful, and avoid escalating public conflict while a report is being reviewed.

Maintainers may remove comments, close issues, restrict participation, or take other reasonable action to keep the project healthy.
