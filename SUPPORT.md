# Support

SST is community-maintained software for DayZ server owners and admins. Please use the right channel so bugs, setup help, and security reports stay easy to handle.

## Before Asking For Help

Check:

- [Getting Started](docs/wiki/Getting%20Started/index.md)
- [Configuration](docs/wiki/Getting%20Started/Configuration.md)
- [First Run Checklist](docs/wiki/Getting%20Started/First%20Run%20Checklist.md)
- [Troubleshooting](docs/wiki/Help/Troubleshooting.md)
- [Known Issues](docs/wiki/Help/Known%20Issues.md)

## Where To Ask

- Use a bug report for reproducible problems in SST.
- Use a support question for installation or configuration help.
- Use a feature request for new behavior or integrations.
- Use a documentation issue when a guide is missing or unclear.
- Do not open public issues for security vulnerabilities. Follow [SECURITY.md](SECURITY.md).

## What To Include

For support questions, include:

- Hosting type: local, dedicated box, hosted provider, Docker, or other.
- Operating system.
- DayZ map or mission.
- Node.js version.
- SST API and dashboard commands you ran.
- Relevant logs with secrets and player-sensitive data removed.

## Data Safety

Never post API keys, JWT secrets, FTP/SFTP passwords, hosting panel tokens, private player data, or full server logs that include personal information. Redact first.

## Response Expectations

This project is maintained by volunteers. Clear, reproducible reports are much more likely to get help. Maintainers may close duplicates, stale issues, or requests that do not include enough detail after follow-up.
