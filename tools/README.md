# Tools

Project tooling is grouped by job:

- `dayz/` - DayZ PBO build and Workbench helper scripts.
- `installer/` - all-in-one Windows setup EXE builder.
- `launchers/` - implementation scripts behind the small root `.bat` wrappers.
- `maintenance/` - local cleanup and factory reset scripts.
- `manager/` - SST Manager Windows wrapper source and build script.
- `map/` - map asset tooling.
- `setup-wizard/` - legacy first-run configuration wizard.
- `updater/` - dashboard-triggered local update scripts.
